# 术语表

## 核心术语

**模块**
: 实现平台契约的可复用策略构件。

**模块类型**
: 用于决定模块在组合中职责和校验方式的类别声明。

**上下文**
: 模块共享的运行时对象，承载当前数据、中间结果和模块输出。

**组合**
: 按顺序排列并组装成一个策略定义的模块集合。

**注册中心**
: 负责模块发现、解析与实例化的受控边界。

**准备层**
: 在校验完成前，负责顺序规范化和批准默认补全的阶段。

**校验**
: 用于确认模块集合对目标运行模式结构正确、语义可接受的一组检查。

**运行模式**
: 模块面向的执行上下文，例如实盘导向或回测导向。

**契约测试**
: 验证模块是否遵循公开扩展面，而不只是测试其内部业务逻辑的测试方式。

**公开 API 边界**
: 允许外部模块开发者依赖的契约与行为集合。
